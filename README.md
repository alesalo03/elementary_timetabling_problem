# elementary_timetabling_problem
This repository contains code and files used for the project activity I developed during my Master in Computer Engineering.

## Index
- <u>main_orari_1.py:</u>, <u>main_orari_2.py:</u>, <u>main_orari_3.py:</u> and <u>main_orari_4.py:</u> are the script file with all the 4 different CP-SAT configurations adopted.
- <u>test_input_adaptive.xlsx</u> is a test file provided to the scripts as input.
- <u>gemini_code.py</u> is the script generated by Gemini Pro to resolve the problem described.
- <u>run_orari.sh</u> is a shell program used to execute all the main_orari.py files consecutively and without letting the pc go in rest mode.
