# elementary_timetabling_problem
This repository contains code and files used for the project activity I developed during my Master in Computer Engineering.

## Index
- main_orari_1.py, main_orari_2.py, main_orari_3.py and main_orari_4.py are the script file with all the 4 different CP-SAT configurations adopted.
- test_input_adaptive.xlsx is a test file provided to the scripts as input.
- gemini_code.py is the script generated by Gemini Pro to resolve the problem described.
- run_orari.sh is a shell program used to execute all the main_orari.py files consecutively and without letting the pc go in rest mode.
